# AI-Powered Smart Kumbh Mela Administration & Decision Support System
### (Nashik–Trimbakeshwar Simhastha Kumbh Mela 2027–28)

---

# Introduction

The scope of this project is to develop a centralized AI-powered Decision Support System that assists government authorities in planning, monitoring, analyzing, and managing various activities of the Nashik–Trimbakeshwar Simhastha Kumbh Mela 2027–28.

The system will integrate multiple administrative departments into a single digital platform and provide dashboards, predictive analytics, intelligent reporting, and resource management features to improve operational efficiency and decision-making.

# Project Limitations

The academic version of the project has the following limitations:

- Uses simulated datasets where real government data is unavailable.
- Only crowd prediction, crowd-risk classification, and traffic-congestion prediction are currently implemented ML models. Budget, medical-demand, waste, resource, water, electricity, and high-risk-zone prediction remain planned features.
- The AI assistant uses database-context augmentation for Ollama; it does not yet use embeddings or a vector database for retrieval.
- Maps and chart widgets currently include sample/static visualization data alongside the live CRUD modules.
- Automated report generation is planned and is not currently implemented.
- Does not connect directly with government databases.
- CCTV analysis is simulated.
- IoT devices are not physically integrated.
- Drone monitoring is not implemented.
- GPS tracking is demonstrated using sample data.
- Live emergency communication systems are outside the project scope.
